📖 1. Official Standard Reference: ECMA-262 Section 12

"ECMAScript code is expressed as a sequence of characters conforming to the rules for SourceCharacter. The lexical grammar defines how sequences of input characters are divided into a sequence of input elements consisting of tokens, line terminators, comments, and white space."

— ECMA-262 16th Edition (ECMAScript 2025), Section 12

In ANTLR4, the Lexer scans characters using Regular Expressions and emits Tokens. According to the specification, keywords take absolute precedence over identifiers when matched against identical character sequences.

🏷️ 3. Identifier Specification: ECMA-262 Section 12.6

In ECMAScript, identifiers are names used for variables, functions, and properties. The formal specification rules state: 

IdentifierName ::
    IdentifierStart
    IdentifierName IdentifierPart

IdentifierStart ::
    UnicodeIDStart
    $
    _

IdentifierPart ::
    UnicodeIDContinue
    $
    _
ANTLR4 Implementation Rule: 
IDENTIFIER : [a-zA-Z_$] [a-zA-Z0-9_$]* ;
Crucial note on rule ordering: Keywords are defined above IDENTIFIER in the grammar file. Because ANTLR evaluates top-down, any exact match with a keyword produces that keyword's token (e.g. CONST), while compound names (e.g. constantValue or $elem or _temp) match IDENTIFIER.
